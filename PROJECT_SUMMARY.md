## 🚀 How to Use

### Option 1: Test Immediately (0 minutes)
```bash
# Just open this file in your browser:
open frontend/offline.html
```

### Option 2: Quick Start (2 minutes)
```bash
# Run automated setup:
./deploy.sh

# Then start the server:
cd backend
npm start

# Access at: http://localhost:3000
```

### Option 3: Manual Setup (5 minutes)
```bash
# 1. Install dependencies
cd backend
npm install

# 2. Configure environment
cp .env.example .env
# Edit .env with your settings

# 3. Start server
npm start

# 4. Open browser
# http://localhost:3000
```
